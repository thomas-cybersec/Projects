# Thomas — Ciberseguridad 

Estudiante autodidacta de ciberseguridad defensivas y análisis de SOC.
Construyo laboratorios, ejecuto escenarios de ataque controlados y 
documento el proceso de detección de principio a fin,de manera que cada 
proyecto funcione tanto como registro de mi aprendizaje como material 
de referencia para quienes se inician en el área.

El enfoque es práctico y teórico: cada proyecto practico parte de una
infraestructura montada, la cual esta registrada, y un análisis de lo que el
equipo defensivo observa, detecta o pasa por alto. Todo el material es
reproducible y está documentado en detalle.
